BEYOND MY BENGAL
Website Installation Guide

1. Keep all files in the same main folder.

2. Your folder structure should be:

beyond_my_bengal_complete/
│
├── index.html
├── details.html
├── passport.html
├── script.js
├── pages.js
├── style.css
├── pages.css
├── README.txt
│
└── assets/
    └── logo.png

3. Upload all files to your GitHub repository.

4. Do not change the file names.

5. Keep the assets folder and logo.png in the correct location.

6. Open index.html to view the website.

7. Destination pages open through details.html.

8. Passport information is stored in the visitor's browser.
   It is not connected to an online database.
